Features

Everything you need to drive your PC from the couch

Built for real use on a small touchscreen: fast video, precise input and the shortcuts you reach for every day.

  • Streams at GPU speed

    DXGI Desktop Duplication captures the screen and NVIDIA NVENC, Intel Quick Sync or AMD AMF encode H.264, decoded on the phone with WebCodecs. JPEG fallback, quality presets and flow control that adapts to the network.

  • A touchpad that feels right

    Pointer acceleration, tap and double-tap, two-finger scroll and right-click, pinch-to-zoom and long-press drag. Prefer pointing? Switch to direct touch and tap exactly where you want to click.

  • Type in any language

    Live typing sends exactly what your phone keyboard produces — Vietnamese and other IMEs, autocorrect, emoji. Sticky Ctrl/Alt/Shift/Win, F-keys and 20+ one-tap shortcuts.

  • Alt+Tab for your thumb

    A window switcher with live thumbnails and app icons. Jump, close or show the desktop in one tap — or swipe three fingers sideways to flip back to the previous window.

  • Made for landscape

    Turn the phone sideways and the laptop screen fills the display. Controls move to a slim side rail and open as drawers only when you need them.

  • System controls

    Media keys and volume, laptop brightness, two-way clipboard, open a link on the laptop, and lock, sleep, hibernate, restart or shut down — with a confirmation for anything disruptive.

  • Reach it from anywhere

    One switch opens an encrypted Cloudflare tunnel with an HTTPS link. No port forwarding, no router setup, no account — and HTTPS unlocks hardware H.264 on the phone.

  • Lives quietly in the tray

    A native Windows app with a tray icon, Start menu entry and optional autostart. Installs per user in seconds and uninstalls cleanly from Settings → Apps.

  • Secure by default

    A private access token in the QR code, brute-force protection and a control dashboard that only opens on the laptop itself. Rotate the token or disconnect a device any time.

How it works

Up and running in under a minute

  1. 1

    Install on Windows

    Download DanceRMD.exe and open it. It installs to your Start menu without admin rights and keeps running in the system tray.

  2. 2

    Scan the QR code

    Point your phone's camera at the code in the DanceRMD window. The link carries your private access token, so the phone connects straight away.

  3. 3

    Take control

    Use the touchpad, keyboard, window switcher and system panel. Leaving the house? Turn on remote access and scan the new HTTPS code.

Remote access

Leave the Wi‑Fi. Keep the control.

Flip one switch and DanceRMD starts a Cloudflare quick tunnel. Your phone gets an HTTPS link that works over 4G or any network — no port forwarding, no router settings, no account.

  • HTTPS to Cloudflare, then an encrypted outbound tunnel to your laptop
  • HTTPS enables hardware H.264 decoding in the phone browser
  • cloudflared is downloaded once and its digital signature verified
  • A fresh link every time you turn it on; the access token is still required

Security

Private by design

Remote control is powerful, so DanceRMD keeps the door locked and puts you in charge of the key.

  • Access token in the QR code

    Every connection must present a random token, checked in constant time. The phone stores it and removes it from the address bar.

  • Brute-force protection

    Repeated wrong tokens from the same address are blocked for a minute, so guessing is impractical.

  • Dashboard stays on the laptop

    The control panel that shows the token only answers local requests. Host and Origin checks stop DNS rebinding, and form-style cross-site requests are rejected.

  • Rotate and disconnect

    See every connected device, disconnect one, or rotate the token to sign out all phones at once.

  • Admin rights only when you ask

    Windows blocks normal apps from controlling elevated windows such as Task Manager. DanceRMD explains the block, and an optional admin mode lifts it with a single UAC prompt.

  • No accounts, no telemetry

    Traffic stays on your local network. It only goes through Cloudflare's encrypted tunnel when you switch remote access on.

FAQ

Questions, answered

Do I need to install an app on my phone?

No. DanceRMD runs in any modern mobile browser — Chrome, Safari, Samsung Internet, Edge or Firefox. You can add it to your home screen for a full-screen, app-like experience.

Does it work when I'm away from home?

Yes. Turn on Remote access in the DanceRMD window and scan the new QR code. The link uses a Cloudflare quick tunnel and changes each time you switch it on. If you already use Tailscale, DanceRMD also lists your Tailscale address.

Why do I see JPEG instead of H.264?

Phones decode H.264 through WebCodecs, which browsers only enable on secure (HTTPS) pages. The remote access link is HTTPS, so it gets H.264; a plain local address falls back to JPEG, which still works well on Wi‑Fi.

Why can't I click inside Task Manager?

Windows prevents normal apps from sending input to windows running as administrator (a protection called UIPI). The phone shows a banner when this happens. Enable Run as administrator in DanceRMD once — Windows asks for confirmation a single time — and elevated windows work too.

Is it safe to leave running?

Only devices that have your access token can connect, wrong guesses are rate-limited and the dashboard is reachable only from the laptop. If you think someone saw your QR code, rotate the token and every phone is signed out.

Does it support multiple monitors?

Yes. Pick a screen in the settings or tap the screen badge to cycle through them. When you switch to a window on another monitor, the stream follows it automatically.

How much does it cost?

Nothing. DanceRMD is free and open source under the MIT license. Issues and pull requests are welcome on GitHub.
